# Greenfield.Content.Buildings

World-building kit bundles (Unity AssetBundles: the shared bundle plus one pack per kit) the Greenfield app downloads after install.

Published by the Content Publisher in the Greenfield Unity project (Greenfield > Content Publisher), one release per content version (e.g. `android-dev-v7`). The app finds files through the signed index in [Greenfield.Content.Index](https://github.com/SideQuestVR/Greenfield.Content.Index) and checks every file's sha256. Do not edit releases by hand.
